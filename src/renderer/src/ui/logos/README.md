# Vendored logos

The logos TinyCorp draws beside somebody else's product: one `.svg` per Provider or MCP preset
that has one, exactly as its icon set publishes it. `docs/brand-logos.md` is what
they may be used for, what may be done to them (nothing), and how to add one.

Neither package below is a dependency of this app — only the individual files drawn are here.
